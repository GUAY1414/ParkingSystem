# Kuya meron pa?

An integrated digital parking management, vehicle verification, and payment system for Manila.

## Current Status

Phase 1 — Requirements and System Planning is in progress.

## Approved Decisions

- PayMongo sandbox for online payment development
- Tesseract.js for initial browser-side OCR
- Leaflet and OpenStreetMap for maps
- Supabase for authentication, PostgreSQL, storage, and Row Level Security
- Fixed parking fees per parking session
